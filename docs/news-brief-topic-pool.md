# 重点简报选题池

## 选题标准

进入“重点简报”的内容必须至少满足 2 条：

- 有 Amazon 官方公告、Seller Central、官方博客或后台通知作为来源。
- 对新手卖家的 Listing、广告、Review、账号健康、AI 搜索或库存决策有直接影响。
- 有明确生效日期、灰度范围、功能上线或规则变化。
- 可以和站内已有内容形成应对方案，而不是只转述新闻。

不满足官方来源的内容，只放入“观察池”，不作为重点简报发布。

## 优先级规则

| 优先级 | 标准 | 响应时限 |
|---|---|---|
| P0 | 规则生效、账号风险、Listing 批量影响 | 24 小时内出简报 |
| P1 | AI 搜索入口、广告后台、Review 或品牌功能明显变化 | 3 天内出简报 |
| P2 | 趋势型更新、工具体验变化、卖家可逐步适配 | 7-14 天内纳入专题更新 |

## 发布后回填

重点简报发布后，在本文件把状态改为：

- `已发布`：独立重点简报已经上线。
- `已纳入专题`：不单独发简报，但已补进专题文章。
- `观察`：信息不足或影响不明确。
- `撤销`：证实不是有效变化或不适合本站用户。
